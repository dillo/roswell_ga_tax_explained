# Roswell Property Tax, Explained

An accessible guide to understanding property taxes for homeowners in Roswell, Georgia.

## Run locally

This Mac has a separate Homebrew installation of `libvips`. Sharp will otherwise try to compile against it instead of using its packaged Apple Silicon binary. Use the setup command once after cloning:

```bash
npm run setup
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To create a production build:

```bash
npm run build
```
